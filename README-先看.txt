聲音頻率播放器 v1.2｜教師課堂演示
=================================

【v1.2 變動】
1. 移除「20 Hz 以下不輸出」的人為音訊限制。1–19 Hz 也會向音訊輸出系統送出相應頻率的正弦訊號；0 Hz 不輸出交變聲音（靜音）。
2. 預設訊號振幅從 v1.1 的 0.075 提升到 0.15（約兩倍振幅，+6 dB 的數位訊號幅度）；保持原本的漸入／漸出與平滑變頻。
3. 不增添介面上的文字或功能，維持一條非線性滑桿、Hz 數值輸入及播放／停止鍵。
4. PWA 離線快取更新為 v1.2；內附 PPT Content Add-in 實驗設定檔。

【立刻使用】
- 可直接開啟 Hearing-Player-v1.2-standalone.html，或在此資料夾開啟 index.html。
- 1–19 Hz 即使軟體已送出訊號，普通喇叭／手機／平板通常無法有效重現該頻率，亦可能產生失真或諧波。聽到聲音不能單獨證明聽到了 15 Hz 基頻。
- 0 Hz 不代表「0 Hz 聲音」，而是沒有交變振動，維持靜音。
- 聲音大小與實體喇叭、音效卡、系統音量等有關，增加數位振幅不等於聲壓等比例增加。
- 因本版音量再次提高，第一次播放前請調低電腦音量，尤其測試 1–19 Hz 時不要為了追求可聽見而調大音量；切回中高頻可能突然很大聲。

【上傳 GitHub Pages】
- 將 ZIP 中所有檔案解壓縮，放進 GitHub Repository 根目錄（不要只上傳 ZIP）。
- Settings > Pages > Deploy from a branch > main > root。
- 假設 Repository 名稱為 Hearing-Player，網址為 https://pipipopo7410.github.io/Hearing-Player/。
- 預設 PWA 可在第一次連網載入後離線使用；若仍顯示舊版，重新整理頁面使新的 Service Worker 完成更新。
- home-button.js 沿用既有定稿，未修改腳本。

【PowerPoint】
- 內附 powerpoint-content-addin.xml 實驗設定檔，需要用 PowerPoint 支援的增益集部署流程。
- 也可以嘗試 Web Viewer 2.0 類增益集，載入 GitHub Pages 網址。
- 尚未在使用者的 PowerPoint 放映環境實測內嵌音訊，因此不能保證各電腦與各版本均支援。

【教學提醒】
- 20–20,000 Hz 是常見的人耳聽覺範圍概數，並非固定生理絕對界線；聽力也與聲音強度有關。
- 聲音頻率增為兩倍時，相當於增加一個八度；因此非線性滑桿更適合比較音高。
- 本播放器不是聽力測量儀器。避免用高音量測試極低頻或極高頻；切忌用耳機進行高聲壓掃頻。
