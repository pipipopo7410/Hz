聲音頻率播放器 v1.3｜15 個音階快捷鍵
==================================

【本次修改】
在 v1.2 原始網站上新增 15 個音階按鈕，中央 Do（C4）起始，至高高音 Do（C6）結束：

  Do  C4   262 Hz       Re  D4   294 Hz       Mi  E4   330 Hz
  Fa  F4   349 Hz       Sol G4   392 Hz       La  A4   440 Hz
  Si  B4   494 Hz       Do  C5   523 Hz       Re  D5   587 Hz
  Mi  E5   659 Hz       Fa  F5   698 Hz       Sol G5   784 Hz
  La  A5   880 Hz       Si  B5   988 Hz       Do  C6  1047 Hz

對應 12 平均律（A4 = 440 Hz），按鍵使用適合現有播放器的整數近似值。

【操作】
- 按任一音階鍵，上方的 Hz 數字與非線性頻率拉桿立即同步跳到對應位置。
- 如果當時正在播放純音，會平滑調整到新頻率，不需要再按播放。
- 如果當時停止播放，選音只設定頻率，不會自行發聲；按原本的「播放」即可。
- 原本的直接輸入頻率、連續拖拉、0–21,000 Hz 範圍、音量設定 0.15 與首頁浮動按鈕均保留。
- 自動標示目前恰好對應的音階按鈕；若手動調到其他頻率則取消選取。

【更新已存在的 GitHub 網站】
1. 解壓縮 ZIP，不要把 ZIP 直接放到 GitHub 網站檔案中。
2. 在原本的 GitHub Repository 上傳本 ZIP 的網站檔案，讓相同檔名覆蓋舊版。
3. GitHub Pages 沿用原本網址，毋須改 PPT 超連結。
4. 如果更新後仍顯示舊版，重新整理一到兩次；此版已更新 PWA 快取版本 v1.3.0。

【離線與音量】
- 首次連網安裝／載入後，網站可由 PWA 快取離線使用；standalone.html 也可直接離線開啟。
- 1–19 Hz 仍會產生相應的訊號，但多數設備不易正確重現極低頻。
- v1.2 的音量設定未變，請先以較低的電腦／喇叭音量試播。
- 不要為了尋找極低頻／極高頻聽覺上限而增加到不安全的聲量。
